============================================================
실습 9~12 처음 읽기 / 실행 방법
============================================================

1. Visual Studio에서 컴그.slnx를 연다.
2. 솔루션 탐색기에는 Practice09, Practice10, Practice11, Practice12가 있다.
3. 실행하고 싶은 프로젝트를 마우스 오른쪽 버튼으로 누른다.
4. '시작 프로젝트로 설정'을 누른다.
5. Ctrl + F5를 눌러 실행한다.

[파일 연결]
Practice09 -> 컴그\1-9.cpp
Practice10 -> 컴그\1-10.cpp
Practice11 -> 컴그\1-11.cpp
Practice12 -> 컴그\1-12.cpp

네 C++ 파일이 함께 사용하는 것:
컴그\PracticeCommon.h
컴그\vertex-basic.glsl
컴그\fragment-basic.glsl

[공부 순서]
1. 먼저 공통_OpenGL_GLSL_설명.txt를 읽는다.
2. 원하는 실습의 코드설명.txt에서 '전체 흐름'을 읽는다.
3. C++ 파일에서 설명에 나온 함수 하나만 찾아 읽는다.
4. 직접 숫자 하나(속도, 색, 크기)를 바꾸고 실행한다.
5. 예상과 실제 결과가 왜 같은지 말로 설명해 본다.

[이전 코드와 가장 큰 차이]
이전 Simple2D.h 방식은 Renderer 클래스와 vector가 많은 일을 대신했다.
새 코드는 PDF에서 배운 내용을 눈으로 확인할 수 있도록 아래처럼 바꿨다.

- vector 대신 크기가 정해진 배열을 사용한다.
- 클래스 대신 struct로 자료만 묶는다.
- 각 행동을 이름이 분명한 작은 함수로 나눈다.
- VAO/VBO와 glBufferSubData, glDrawArrays를 직접 호출한다.
- GLSL을 별도 파일로 두고 직접 컴파일/링크한다.
- 상태를 bool, int, float 변수로 눈에 보이게 관리한다.

Simple2D.h 파일은 예전 실습과 비교할 수 있도록 남겨 두었지만,
새 실습 9~12는 더 이상 Simple2D.h를 include하지 않는다.

[PDF 밖이지만 꼭 필요한 부분]
GLFW 창 생성, GLEW 초기화, std::ifstream 파일 읽기는 프로그램을 실제로
실행하기 위한 준비 코드다. 도형 이동/충돌/그리기 원리는 PDF의 배열, 구조체,
조건문, 반복문, 함수, VAO/VBO, 셰이더 컴파일/링크 범위로 작성했다.
