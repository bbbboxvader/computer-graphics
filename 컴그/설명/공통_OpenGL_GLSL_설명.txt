1. 화면 좌표를 종이라고 생각하기
------------------------------------------------------------
OpenGL의 기본 화면은 가로와 세로가 모두 -1.0부터 1.0까지다.

             y = 1
               위
 x = -1  왼쪽  (0,0)  오른쪽  x = 1
               아래
             y = -1

예: (0, 0)은 화면 한가운데, (-0.5, 0.5)는 왼쪽 위쪽이다.

2. PracticeCommon.h 줄별 역할
------------------------------------------------------------
17줄: PI는 원 운동과 회전에 쓰는 원주율이다. const라서 실행 중 바뀌지 않는다.
19~27줄 Vertex: 정점 한 개가 위치 x,y,z와 색 r,g,b를 한 상자에 보관한다.
29~35줄 ShapeType: 도형 종류를 숫자 대신 SQUARE, TRIANGLE 같은 이름으로 쓴다.
37~41줄 Point2D: x와 y만 필요한 점을 보관한다.

43~53줄 MakeVertex
- x, y, r, g, b를 받아 Vertex 한 개를 만들어 돌려준다.
- 같은 여섯 줄짜리 대입을 계속 쓰지 않으려고 만든 함수다.

55~61줄 RotatePoint
- 점을 angle만큼 회전시킨다.
- sin과 cos는 PDF의 GLSL 내장 함수 부분과 같은 원리다.

63~68줄 Distance
- 두 점 사이 거리를 피타고라스 정리로 구한다.
- 실습 10에서 조각이 목표 가까이에 놓였는지 판단한다.

70~74줄 RandomFloat
- minimum부터 maximum 사이의 임의의 실수를 만든다.
- rand()가 만든 큰 정수를 0~1로 바꾼 뒤 원하는 범위로 늘린다.

76~87줄 ReadTextFile
- GLSL 파일의 글을 통째로 읽어 문자열로 돌려준다.

89~112줄 CompileShader
- GLSL 글을 GPU가 이해할 수 있게 컴파일한다.
- 실패하면 오류 메시지를 출력하고 0을 돌려준다.

114~140줄 MakeShaderProgram
- vertex shader와 fragment shader를 각각 컴파일한다.
- 두 셰이더를 glAttachShader로 붙이고 glLinkProgram으로 한 프로그램으로 연결한다.

142~171줄 InitBuffer
- VAO는 '정점 자료를 어떤 규칙으로 읽을지 적은 설명서'다.
- VBO는 '실제 정점 자료를 담는 GPU 상자'다.
- glBufferData는 상자 크기를 먼저 마련한다.
- layout 0은 위치 3개, layout 1은 색 3개라고 GPU에 알려준다.

173~178줄 DrawVertices
- glBufferSubData로 이번에 그릴 정점을 VBO에 넣는다.
- glDrawArrays로 점, 선, 삼각형 중 원하는 방법으로 그린다.

180~240줄 MakeFilledShape
- 도형의 중심, 크기, 회전, 색을 받아 채운 정점 배열을 만든다.
- 사각형은 삼각형 두 개가 필요하므로 정점 6개를 만든다.
- 삼각형 종류는 정점 3개를 만든다.

242~270줄 MakeShapeOutline
- MakeFilledShape가 만든 꼭짓점을 다시 사용해 테두리용 순서로 정리한다.

272~281줄 PointInsideShape
- 마우스가 도형 중심에서 충분히 가까운지 검사한다.

283~294줄 MouseToOpenGL
- 마우스 픽셀 좌표를 OpenGL의 -1~1 좌표로 바꾼다.
- 마우스 y는 위에서 아래로 커지지만 OpenGL y는 아래에서 위로 커지므로 뒤집는다.

3. GLSL 파일 설명
------------------------------------------------------------
[vertex-basic.glsl]
1줄 #version 330 core: GLSL 3.30 문법을 쓰겠다는 뜻이다.
3줄 layout(location = 0) in vec3 vPosition:
  VAO의 0번 위치 자료를 세 숫자 벡터로 받는다.
4줄 layout(location = 1) in vec3 vColor:
  VAO의 1번 색 자료를 받는다.
5줄 out vec3 outColor: 다음 단계로 색을 보낸다.
8~12줄 main: gl_Position에 화면 위치를 넣고 색을 전달한다.

[fragment-basic.glsl]
3줄 in vec3 outColor: vertex shader가 보낸 색을 받는다.
4줄 out vec4 FragColor: 화면에 내보낼 RGBA 색이다.
6~9줄 main: RGB 뒤에 투명도 1.0을 붙여 최종 색을 만든다.

CPU(C++ 코드) -> VBO -> vertex shader -> 도형 조립 -> fragment shader -> 화면

4. 자주 질문받는 문법
------------------------------------------------------------
struct: 서로 관련된 여러 변수를 하나의 상자로 묶을 때 쓴다.
enum: 정수 0,1,2 대신 알아보기 쉬운 이름을 쓸 때 쓴다.
const: 나중에 바뀌면 안 되는 값을 만들 때 쓴다.
배열 a[20]: 같은 종류 상자 20개를 번호로 관리할 때 쓴다.
for: 같은 일을 정해진 횟수만큼 반복할 때 쓴다.
if / else: 조건에 따라 서로 다른 일을 시킬 때 쓴다.
bool: 참(true) 또는 거짓(false)만 저장한다.
void: 함수가 결과값을 돌려주지 않는다는 뜻이다.
return: 함수를 즉시 끝내거나 결과를 돌려준다.
Triangle& t의 &: 원본 상자를 직접 고친다는 뜻이다. 복사본을 고치는 것이 아니다.
const Triangle& t: 원본을 복사하지 않고 읽되, 함수 안에서는 바꾸지 않겠다는 뜻이다.
GLFWwindow*: GLFW가 만든 창을 가리키는 표지판이다.
static_cast<float>: 숫자 자료형을 의도적으로 float로 바꾼다는 뜻이다.
sizeof(Vertex): Vertex 한 개가 메모리 몇 바이트인지 계산한다.
nullptr: 아무 대상도 가리키지 않는다는 뜻이다.

------------------------------------------------------------
5. 프로그램이 시작되고 끝나는 공통 순서
------------------------------------------------------------
1. glfwInit(): GLFW를 준비한다.
2. glfwCreateWindow(): 창을 만든다.
3. glfwMakeContextCurrent(): 이 창에 OpenGL을 연결한다.
4. glewInit(): OpenGL 함수들을 사용할 준비를 한다.
5. glfwSet...Callback(): 키보드나 마우스 담당 함수를 등록한다.
6. MakeShaderProgram(): GLSL 두 파일을 읽고 연결한다.
7. InitBuffer(): VAO와 VBO를 준비한다.
8. while 반복문: 상태 갱신 -> 그리기 -> 화면 교환 -> 입력 확인을 반복한다.
9. glDelete... / glfwTerminate(): 사용한 것을 정리하고 끝낸다.

[예상 질문]
Q. 왜 매 프레임 glClear를 하나요?
A. 종이에 계속 덧그리면 잔상이 남는다. 새 장처럼 지우고 현재 위치를 다시 그리는 것이다.

Q. glDrawArrays의 모드는 언제 바꾸나요?
A. GL_LINES는 두 점씩 선, GL_LINE_LOOP는 마지막 점과 첫 점까지 연결,
   GL_LINE_STRIP은 줄을 이어 그리며, GL_TRIANGLES는 세 점씩 채운 삼각형을 만든다.

Q. deltaTime은 왜 곱하나요?
A. 컴퓨터마다 초당 반복 횟수가 달라도 '1초에 얼마 이동'이라는 속도를 같게 만들기 위해서다.
